시작하기 전 30분 세팅

  1. API 키 두 개를 준비합니다. 생성용(Anthropic) 하나, 임베딩은 코랩 GPU에서 무료로 돌리므로 별도 결제가 필요 없습니다. 임베딩을 API로 돌릴 때만 Voyage나 OpenAI 키를 추가합니다.
  2. 코랩 런타임을 GPU로 바꿉니다. 런타임 → 런타임 유형 변경 → T4 GPU. 무료 등급은 하루 사용 시간 제한이 있으니, 임베딩은 한 번 만들어 .npy로 저장해 두고 재사용합니다(모듈 3).
  3. 키는 코드에 쓰지 않습니다. 코랩 왼쪽 🔑 Secrets에 ANTHROPIC_API_KEY를 넣고 userdata.get()으로 읽습니다. 노트북을 공유해도 키가 새지 않습니다.
  4. 작업 폴더를 정합니다. 이 노트는 imgo-node/content/문제/1차와 imgo-node/content/<과목> 구조를 그대로 전제합니다. 드라이브에 저장소를 두면 코랩에서 바로 마운트할 수 있습니다.
모델 이름은 코드에 박지 마세요

예제 코드는 MODEL = "claude-sonnet-5-5"처럼 변수로 뺐습니다. 모델 ID는 세대마다 바뀌므로, 실제로 돌릴 때는 콘솔의 Models 페이지에서 현재 ID를 확인해 환경변수(CLAUDE_MODEL)로 넣는 편이 안전합니다. 이 노트의 코드는 ID가 아니라 구조를 외우게 하려고 그렇게 썼습니다.

이 코스를 읽는 다섯 가지 원칙

  1. 한 번에 하나만 바꿉니다. 청킹과 프롬프트를 동시에 고치면 무엇이 효과였는지 영원히 모릅니다.
  2. 측정 없는 개선은 취향입니다. “느낌상 좋아졌다”는 모듈 4의 20문항 골든셋으로 대체합니다.
  3. 원문을 믿고, 모델을 의심합니다. 생성 결과는 반드시 원문 근거(성취기준·해설)로 되짚습니다.
  4. 사람이 마지막에 봅니다. 자동화는 후보를 좁히는 일까지. needs_manual_verification 플래그를 지우는 건 사람입니다.
  5. 작은 표본으로 먼저. 8천 문항 전체에 돌리기 전에 20문항으로 실패를 다 만나 둡니다.

지금 상황이 순서로이유
AI 코딩이 처음1 → 2 → 3 → 4순서대로 쌓이게 설계했습니다. 건너뛰면 3장에서 막힙니다.
프롬프트는 써 봤다1장 훑고 → 3 → 4 → 2RAG·채점이 목적이라면 전처리는 그다음에 손보는 편이 효율적입니다.
스캔 PDF가 산더미2 → 3 → 4 → 1데이터가 없으면 검색도 없습니다. 2장을 먼저.
채점 자동화만 급함1 → 44장은 1장의 출력 고정·환각 억제를 전제로 씁니다.
진도는 자동으로 저장됩니다
